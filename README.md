SGB - Sistema de Gestión

¿De qué se trata el proyecto?

SGB es un proyecto que fui desarrollando durante mi formación en la Tecnicatura Superior en Desarrollo de Software.

La idea es tener un sistema formado por una página web y un bot de Telegram. Cada uno cumple una función diferente y ambos forman parte del mismo proyecto.

Durante su desarrollo fui aprendiendo a programar, organizar los archivos, corregir errores y mejorar las distintas partes del sistema.

¿Qué tiene el sistema?

Página web

La página web es la parte que se puede abrir desde una computadora o un celular usando Internet.

Tiene diferentes secciones, formularios y opciones para que el usuario pueda interactuar con el sistema.

Para crearla utilicé:

HTML: para armar la estructura de la página.

CSS: para darle diseño, colores y formato.

JavaScript: para hacer que los botones y las diferentes opciones funcionen.

Podés ingresar a la página desde este enlace:

https://rociomgonzalez.github.io/SGB-SOFTWARE-BOT/

Bot de Telegram

El proyecto también cuenta con un bot de Telegram desarrollado en Python.

Su función es permitir que los usuarios puedan interactuar con el sistema desde Telegram y recibir respuestas según las funciones que tiene programadas.

El bot se encuentra alojado en un servidor AWS para que pueda funcionar sin necesidad de tener mi computadora encendida.

¿Cómo están organizados los archivos?

El proyecto está dividido en dos carpetas principales:

docs: contiene todos los archivos de la página web, como el HTML, CSS, JavaScript y las imágenes.

bot: contiene los archivos necesarios para el funcionamiento del bot de Telegram.

También se encuentra el archivo .gitignore, que sirve para evitar subir archivos privados o que no son necesarios.
